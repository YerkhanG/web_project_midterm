# API Documentation

Base URL: `http://localhost:8000/api`

## Score

| Field | Type | Description |
|-------|------|-------------|
| id | integer | generated by the database |
| player | string | name of the player, max 50 characters |
| game | string | name of the game, max 50 characters |
| points | integer | 0 or more |

## Endpoints

| Method | URL | Description | Status |
|--------|-----|-------------|--------|
| GET | /api/scores/ | list all scores | 200 |
| POST | /api/scores/ | create a score | 201 |
| GET | /api/scores/{id}/ | get a score by id | 200 |
| PUT | /api/scores/{id}/ | update a score | 200 |
| PATCH | /api/scores/{id}/ | update some fields of a score | 200 |
| DELETE | /api/scores/{id}/ | delete a score | 204 |

## List scores

`GET /api/scores/`

The scores are sorted by points, the highest first. Response (200):

```json
[
  {"id": 3, "player": "Zed", "game": "Tetris", "points": 12000},
  {"id": 1, "player": "Nova", "game": "Tetris", "points": 9500}
]
```

If there are no scores, the response is `[]`.

## Create a score

`POST /api/scores/`

Request body:

```json
{"player": "Nova", "game": "Tetris", "points": 9500}
```

Response (201):

```json
{"id": 1, "player": "Nova", "game": "Tetris", "points": 9500}
```

## Get a score by id

`GET /api/scores/1/`

Response (200):

```json
{"id": 1, "player": "Nova", "game": "Tetris", "points": 9500}
```

## Update a score

`PUT /api/scores/1/`

All fields are required.

```json
{"player": "Nova", "game": "Tetris", "points": 15000}
```

Response (200):

```json
{"id": 1, "player": "Nova", "game": "Tetris", "points": 15000}
```

## Update some fields of a score

`PATCH /api/scores/1/`

Only the fields that change are sent.

```json
{"points": 20000}
```

Response (200):

```json
{"id": 1, "player": "Nova", "game": "Tetris", "points": 20000}
```

## Delete a score

`DELETE /api/scores/1/`

Response (204): empty body.

## Errors

404 - a score with this id does not exist:

```json
{"detail": "No Score matches the given query."}
```

400 - the data is not valid. For example, `POST /api/scores/` with `{"player": "", "points": -5}`:

```json
{
  "player": ["This field may not be blank."],
  "game": ["This field is required."],
  "points": ["Ensure this value is greater than or equal to 0."]
}
```
